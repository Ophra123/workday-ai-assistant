# Workday AI Assistant

Build a working, responsive web app called AI Workplace Productivity Assistant using React, TypeScript, and Tailwind CSS.

Design: Premium dark-purple SaaS dashboard, violet accents, sidebar navigation, clean cards, mobile-responsive layout.

Features:

Email Generator: Generate complete, natural emails from user instructions. Support Formal, Friendly, and Persuasive tones. Include editable output and a copy button.

Research Assistant: Answer topic questions, summarise pasted text, extract key insights, and give relevant recommendations.

AI Chatbot: Natural, contextual conversations with relevant follow-up questions and conversation history.

AI functionality: Use a genuinely available AI integration that works without Lovable Cloud, a custom backend, or paid subscriptions. Before building, verify that the chosen integration is supported and accessible. Never use hardcoded responses or claim simulated text is AI-generated. Never expose secret API keys in frontend code. If no secure, free AI integration is available, build the complete functional interface and clearly explain the remaining connection requirement.

Include loading states, error handling, empty-input validation, editable results, copy buttons, and a responsible AI disclaimer.

Important: Build the complete MVP in one pass. Keep dependencies minimal, avoid unnecessary features, do not redesign after building, and test all three tools. Prioritise a working application over visual complexity.
